> A comprehensive communication workflow management system for Philippine Navy's C4 SYSTEMS (NS FOR CAISRS)

## 📋 Overview

C4 SYSTEMS is a web-based communication workflow management platform designed for military and government organizations. It streamlines the creation, approval, and release of official communications with robust compliance tracking.

### 🔑 Key Features

- **📝 Communication Management** - Create, edit, and track communications
- **✅ Multi-level Approval Workflow** - Role-based approval system (Specialist → POIC → AN6A → N6A-N6G → EXO → DN6 → N6)
- **📊 Analytics Dashboard** - Real-time insights and metrics
- **📋 Compliance Tracking** - Monitor and manage compliance requirements
- **📎 Export Capabilities** - Export to Excel and CSV formats
- **👥 User Management** - Role-based access control (Admin, Approver, Creator, Viewer)
- **🌓 Dark/Light Theme** - Professional military-grade dark mode
- **📱 Responsive Design** - Works on desktop, tablet, and mobile
